## Summary

This laboratory investigated memory hierarchy, cache locality, false sharing, and parallel scaling on an AMD Ryzen 5 5600H processor with 6 physical cores and 12 threads. The memory stride benchmark demonstrated increasing access latency from 1.20 ns at stride 1 to 6.85 ns at stride 128. Loop interchange significantly improved matrix multiplication performance, achieving a 53.19x speedup. False sharing experiments showed that padded counters performed better than unpadded counters, while local privatization achieved the lowest execution time. Strong scaling reached a 2.30x speedup using 4 processes, with 57.48% parallel efficiency. Weak scaling demonstrated decreasing efficiency as the workload increased. The Roofline analysis estimated an arithmetic intensity of 0.104 FLOPs/byte, indicating a memory-bandwidth-bound workload. All recorded numerical correctness checks passed.
